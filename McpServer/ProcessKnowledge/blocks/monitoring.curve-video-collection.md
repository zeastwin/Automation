# 曲线与视频采集通道

## 可观察目标

按工位/保压点/相机拆分的采集通道，常驻循环采集压力曲线、电批锁付曲线或视频录制/截图，数据与工位身份绑定后交给上传链路。

## 适用边界

PLC 主控工艺、PC 只做采集的架构；通道只采集与绑定身份，不判工艺好坏、不控制执行机构。双工位或多保压点用同构通道复制，不合并成单流程轮询。

## 当前事实与适配

通道命名携带工位与采集对象（压力曲线_A工位保压1..N、电批1(SW)曲线绘制、Video_1录制）；录制与截图/加载图片是不同通道；采集启动由 PLC 侧信号触发，PC 端只被动跟随；曲线数据与载体身份在通道内绑定后才可上传。

## 参考阶段

1. 等待 PLC 侧采集触发信号；
2. 建立采集会话（曲线采样或视频起录）；
3. 收齐本次数据并绑定载体身份；
4. 通知上传链路并等待下一触发。

## 完成证据

每个工位/保压点的数据都能与其身份对应；同构通道结构一致；触发信号丢失时通道保持等待而不采集脏数据。

## 失败、超时与恢复

采集中途断链按本次作废处理，不产出半条曲线；触发后超时未收齐报警并复位会话状态；视频文件写失败不影响下一段录制。

## 反模式

- **主动轮询代替触发跟随**：PC 端自己定时采样，与 PLC 工艺节拍脱节，采到空拍或重拍。被动跟随 PLC 触发信号。
- **数据不绑身份就上传**：曲线文件名与载体对不上，追溯时无法归位。通道内完成身份绑定后才交上传。
- **半条曲线也上传**：采集中断后把残缺数据交上去污染数据库。断链按本次作废。
- **多工位合并单流程轮询**：A/B 工位曲线挤在一个流程里，一次触发互相干扰。按工位同构通道复制。

## 幂等与甄别结论

一次触发一次会话，重复触发以 PLC 侧节拍为准去重。固定通道地址、保压点数量、文件命名规则不吸收；按工位拆通道、身份绑定后才可上传、被动跟随触发、作废不补半条数据被保留。
