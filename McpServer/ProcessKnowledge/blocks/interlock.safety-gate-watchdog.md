# 安全门禁联锁监控

## 可观察目标

安全门或围栏被打开时设备运动立即暂停并报警，全部闭合恢复后释放暂停继续运行；全程不丢失当前作业上下文，监控自身常驻不退出。

## 适用边界

适用于依赖门禁开关输入与跨流程共享暂停变量的设备。调机/手动模式通常放行生产保护；无门禁硬件或由安全PLC硬切回路的场合不适用本块。

## 当前事实与适配

需要：前后所有门禁输入信号、模式变量（生产/调机）、跨流程共享的暂停变量、可区分来源的报警信息通道；有门锁执行器时纳入控制范围。历史信号编号、固定门数与暂停变量名不得复用；任何门禁屏蔽标志默认必须为关闭态。

## 参考阶段

1. 常驻自启：独立小流程自启动循环检测，不依赖生产流程拉起。
2. 模式门控：仅在需要保护的模式（生产/自动）下检查；调机模式跳过检测。
3. 全门逐一检测：前门、后门等依次检查闭合状态，不抽样。
4. 违规处置：置共享暂停变量=1，弹框报警并区分是哪个门，循环重新检测等待闭合；有门锁执行器时在保护模式下锁定，防止运行中开门。
5. 恢复处置：全部闭合后置暂停变量=0，回到常规轮询。

## 完成证据

违规时暂停变量为 1 且作业流程实际暂停；恢复后暂停变量为 0 且作业继续。仅出现弹框不构成暂停证据；暂停变量置位但作业未暂停是联锁失效。

## 失败、超时与恢复

门禁信号抖动按轮询周期容忍；报警期间人工闭合门禁即恢复，无需重启流程；若报警需人工确认，先确认再清暂停变量，顺序不可颠倒。

## 幂等与甄别结论

暂停变量置 1/清 0 幂等，重复检测无副作用。旧项目的启用门禁标记开关变量、固定前后门信号编号未被保留；共享暂停变量联动（监控不直接停机）、区分门来源的报警、模式门控被保留。
