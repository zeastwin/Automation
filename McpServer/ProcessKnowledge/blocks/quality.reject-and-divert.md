# NG品判定后抛料分流

## 可观察目标

把已判定为 NG 的产品从正常物流安全移出到 NG 仓或抛料位，保留判定原因可追溯，NG 仓满时请求人工处理；整个过程不影响合格品流。

## 适用边界

适用于有既有 NG 判定结果（检测/复检产出）且有 NG 仓或抛料位的设备。判定本身（视觉/测量）不在本块；无 NG 存放位的设备只能停止并报警，不适用本块。

## 当前事实与适配

需要：按穴位或槽位的 NG 判定结果变量、NG 仓到位与穴位占用传感器、取放机构与安全点位、人工解锁或交互信号、合格与 NG 分流出口。历史穴位数量、固定点位索引与固定变量名不得复用。

## 参考阶段

1. 判定与执行分离：先依据既有 NG 判定结果确定要抛出的穴位清单，再逐个执行；抛料流程内不重新判定质量。
2. 前置安全三查：人工解锁确认、NG 仓到位检测、当前穴位有料检测；任一不满足则报警等待，不开始运动。
3. 安全取放时序：移动到上方，XY 对位，Z 下到抛料位，松开夹爪或破真空，停止轴运动，回到上方。
4. 逐位循环：索引递增遍历 NG 穴位，每次抛放后置完成标志；已空穴位跳过不重复动作。
5. 仓满处置：NG 盘满时报警请求人工取出，不自动清零继续抛料。

## 完成证据

全部 NG 穴位清空（穴位传感器无料）、完成标志置位、NG 品实际位于 NG 仓、合格品流未受影响。部分抛出不算完成。

## 失败、超时与恢复

抛料中机构不到位时报警停止当前循环，保留索引与未抛清单；人工解锁必须在运动前成立，防止人手在仓内；仓满转人工后继续时索引不回滚，从剩余穴位续抛。

## 幂等与甄别结论

完成标志加索引使中断重入可续抛；对已空穴位重复执行无副作用。旧项目的固定穴位数、固定点位索引、蜂鸣器提示与被禁用的抛料盘满自动清零未被保留；判定与执行分离、前置安全三查、上方-XY-Z 的安全取放时序、仓满人工处置被保留。
