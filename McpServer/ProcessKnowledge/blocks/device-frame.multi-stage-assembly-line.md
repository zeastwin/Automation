# 多段组装回流线设备框架

## 设备画像

单机内多个工艺段（如前/后 MLA、LCF、保压）串接的组装线：每段"缓存→组装"同构结构，上下料仓拉料供给，机器人/机构取料换料盘，双回流线（每段各一条）回收载具，配套磨吸嘴维护与标定族。NS 全流程形态：流程直接控制轴与 IO。

## 功能单元构成

| 工艺段 | 缓存+组装同构段，按段复制 | 前MLA缓存/组装、后MLA缓存/预进/组装、LCF组装缓存/组装 | transfer.pipeline-station-triad、orchestration.replicated-station-fleet |

## 单元间衔接

物料流：上料仓拉料→进料→段缓存推进→段组装→（保压段）→出料；每段取料机构在段内取料，料盘满/空触发更换料盘计数联动。载具流：每段独立回流线常驻循环回收。维护流：磨吸嘴在生产外独立触发。标定流：段标定后有关联标定把偏移传导到关联工位。

## 框架变化点

段数与段名（2~4 段常见，按机型）；有无保压段；有无串线上料（跨线体接驳）；组装作业规模（历史差异极大，只吸收结构不吸收指令量）；标定级数（段标定+关联标定）。

## 搭建顺序

系统五件套 → 上下料仓拉料 → 进料 → 先建一个完整段（缓存+组装）验证 → 同构复制其余段 → 保压段 → 段回流线 → 取料换盘 → 磨吸嘴 → 标定族 → 一键收料盘收尾。

## 完成证据

从上料仓到出料的全段走通且每段账目一致；各段回流线独立循环不阻塞生产；料盘更换计数与实物一致；关联标定后各段偏移一致生效；一键收上/下料盘可用。

## 反模式

- **段建成就复制**：第一个段没走通验证就同构复制其余段，错误复制 N 份。先建完整段验证再复制。
- **关联标定被省略**：只建段标定不建关联标定，段间偏移不一致。标定族按层级建全。
- **回流线与生产混用机构**：段回流线借用生产机构动作，节拍互相干扰。每段回流线独立常驻循环。
- **磨吸嘴混进作业**：吸嘴维护写在组装作业里生产中等着维护。维护独立流程生产外触发。
- **更换料盘计数脱账**：料盘满/空更换计数与实物对不上。计数与换盘动作成对。

## 黄金样例

> 来源：`be-LCF-and-MLA_3-0_2025-04-16_12-08-12号机12代-改机`。NS 全流程多段组装线的落地参考。

**流程族清单**（54 个流程按单元归组）：系统状态/门禁/灯控/时间/防呆、系统流程、门禁报警｜启动｜进料｜前MLA缓存、前MLA组装｜后MLA缓存、后MLA预进、后MLA组装｜LCF组装缓存、LCF组装｜保压缓存、LCF保压、MLA保压｜出料｜上料、上料仓拉料、下料、下料仓拉料、下料抛料盘｜前/后MLA取料、前/后MLA更换料盘、LCF取料、LCF更换料盘｜左/右MLA保压｜MLA段回流线、LCF段回流线｜磨前/后MLA吸嘴、磨LCF吸嘴｜BC上料标定、前/后MLA标定、后MLA关联标定、LCF标定、LCF关联标定｜前/后MLA取料拍照｜重复性验证｜一键收上/下料盘。段结构（缓存+组装）逐段复制、段标定+关联标定成对出现、每段独立取料与更换料盘——三段同构的特征齐整。

**段骨架**（以前MLA为例）：前MLA缓存（九态推进，承接进料）→ 前MLA组装（Work 段触发作业）→ 前MLA取料（段内取料配合）→ 前MLA更换料盘（料盘满/空计数联动）。段的四个流程就是"缓存+组装+取料+换盘"单元的落地——建段时先走通这一套，再整体复制成后MLA/LCF 段并逐项换前缀。

**标定族分层**：BC上料标定（进料基准）→ 前/后MLA标定、LCF标定（段基准）→ 后MLA关联标定、LCF关联标定（把段偏移传导到关联工位）。标定从进料端到组装端逐级传导，链上任何一级改动都有关联标定消化——只建段标定不建关联标定，段间偏移必然漂移。

**维护与收尾**：磨吸嘴按段独立（磨前/后MLA、磨LCF），MLA/LCF 段回流线各自常驻循环，一键收上/下料盘作为 UI 入口收尾——生产外维护与生产流程的边界在整个流程族里保持干净。

## 幂等与甄别结论

框架只约束段同构、双回流线、标定族分层。历史组装段的数百指令复制文本、固定段数、固定穴位地址不吸收；段同构+缓存推进、段回流线常驻、更换料盘计数、磨吸嘴独立维护、关联标定分层、一键收料盘 UI 入口被保留。复制段时逐项核对点位/变量前缀。
